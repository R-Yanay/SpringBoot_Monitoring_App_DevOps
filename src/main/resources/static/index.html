📊 Spring Boot Monitoring App

DevOps Monitoring Demo mit Prometheus und Grafana

🖥️ Anwendung Status

● RUNNING

Die Anwendung läuft auf Port 8080

🔧 Actuator Endpunkte

GET
/actuator/health
Gesundheitsstatus der Anwendung
GET
/actuator/info
Anwendungsinformationen
GET
/actuator/metrics
Alle verfügbaren Metriken
GET
/actuator/prometheus
Metriken im Prometheus-Format (für Scraping)

🎮 Demo Endpunkte

GET
/api/demo/hello
Einfacher Begrüßungs-Endpunkt
GET
/api/demo/slow
Simuliert eine langsame Operation (2 Sekunden)
GET
/api/demo/work
Simuliert rechenintensive Arbeit
GET
/api/demo/error
Simuliert einen Fehler (für Tests)
GET
/api/demo/heavy
Erzeugt CPU- und Memory-Last (10 Mio. Berechnungen, 50 MB)

📈 Monitoring Tools

Nach dem Start mit docker-compose up sind folgende Tools verfügbar:

GET
http://localhost:9090
Prometheus UI - Metriken-Abfrage und -Speicherung
GET
http://localhost:3000
Grafana Dashboard - Visualisierung der Metriken (Login: admin/admin)
GET
http://localhost:3000/explore
Grafana Explore - Loki Logs durchsuchen (Datenquelle: Loki)
